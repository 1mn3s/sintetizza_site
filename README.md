# Sintetizza LP SEO

Landing page da Sintetizza Estruturas focada em SEO local, velocidade e conversão.

## Publicação
Este repositório é a base separada de GitHub Pages da landing page.

## Foco
- locação de tendas em Sorocaba e região;
- palcos, Box Truss e galpões;
- climatizadores;
- LED, som e iluminação;
- infraestrutura para eventos;
- CTA direto para WhatsApp.

## SEO
HTML semântico, H1 único, conteúdo indexável, LocalBusiness/EventService, FAQPage, canonical, sitemap e robots simplificados.

O domínio canônico permanece `https://sintetizzalocacoes.com.br/` para evitar indexação duplicada da URL técnica do GitHub Pages.
