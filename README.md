# Sintetizza LP SEO

Landing page de conversão da Sintetizza Estruturas, derivada do site institucional original.

## Objetivo
Concentrar autoridade e intenção de busca em uma única página rápida e sem distrações, com foco em:
- estruturas para eventos em Sorocaba e região;
- locação de tendas e galpões;
- palcos e Box Truss;
- climatizadores para eventos;
- painel de LED, som e iluminação;
- orçamento via WhatsApp.

## Estratégia SEO
- HTML semântico e conteúdo rastreável sem depender de JavaScript;
- apenas um H1;
- titles e descriptions orientados a intenção local;
- canonical para `https://www.sintetizzalocacoes.com.br/`;
- JSON-LD com LocalBusiness/EventService, WebSite e FAQPage;
- conteúdo local para Sorocaba e cidades atendidas;
- sitemap de uma única URL;
- robots simplificado;
- imagem principal carregada com prioridade;
- CSS único e nenhuma biblioteca externa;
- CTA direto para WhatsApp.

## Arquivos principais
- `index.html` — LP completa.
- `css/lp-seo.css` — estilos responsivos.
- `robots.txt` — rastreamento.
- `sitemap.xml` — sitemap da landing page.

## Observação de publicação
Antes de produção, confirme que o domínio final é `www.sintetizzalocacoes.com.br`. Caso outro domínio seja usado, altere canonical, Open Graph, JSON-LD, sitemap e robots para evitar sinais conflitantes ao Google.
